Extraction provenance

Source counts: bundle_footer 15 · bundle_other 16 · config_route 7 · dom_anchor 13

  1. config_route · inline_script_path_scan
    The ~8.5KB inline script on the home page (SSR bootstrap) contains quoted route paths (/deposit, /support, /my-account/kyc, /bet-limits, etc). Run on any page load; results are stable across routes.
  2. bundle_other · prerendered_manifest_registry
    window.__PRERENDERED_MANIFEST__ maps bundle names (footer, seo, navbar, kyc, support, contentHub, header, etc) to hashed JSON filenames at /config/<name>.<hash>.json. This is the JSON bundle registry.
  3. bundle_footer · fetch_and_extract_links
    Fetch the footer.<hash>.json bundle resolved from the manifest (step 2). j.links.defaultVariation.sections[].items[] gives {name, link} pairs for compliance/legal doc pages (terms, privacy, offers, AML/KYC, responsible gambling, self-exclusion, dispute resolution). j.licenses and j.legalInformation give license/authority info. Replace FOOTER_FILENAME with the current hashed name from the manifest each crawl (hash changes on deploy).
  4. bundle_other · fetch_and_extract_paths
    navbar.<hash>.json (from manifest) contains typeByPath/typeByRoute maps with many additional account/info/compliance routes (about, press, licenses, cookie-policy, games-rules, fairness testing, mobile, self-exclusion variants). Extract with a generic path-regex scan since keys are route-type identifiers, not human names.
  5. dom_anchor · anchor_scan
    Run on home page and /menu, /support, /sports/lobby to collect visible nav anchors (product landings: casino/slots, casino/live-casino, casino/instant-games, casino/virtual-sports, sports/lobby, football/live, etc). Footer element does not exist in DOM — footer content is entirely bundle-driven (see bundle_footer step).
  6. bundle_other · product_titles_img_alt
    Navigate to /casino/slots or /casino/live-casino, scroll to trigger lazy-load, then read img[alt] text for game tile titles. Game/table page URLs are intentionally not collected (titles only).
